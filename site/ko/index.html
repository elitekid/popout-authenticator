Popout Authenticator — 2FA & OTP Codes

브라우저에서 쓰는 2단계 인증 앱. 암호화된 코드를 팝업·창·사이드 패널로 보고, 허용한 사이트에 바로 넣습니다.

오픈소스(MIT) · 계정 수 제한 없음 · 가입 없음 · 분석 도구 없음

1분 만에 둘러보기

창 열기, 코드 넣기, QR 코드로 추가, 백업 가져오기, 코드 공유, 잠금까지 봅니다. 예시 계정만 썼습니다.

필요한 곳에서 바로 보는 코드

  • 툴바 팝업, 분리 창, 사이드 패널(파이어폭스는 사이드바)에서 코드를 볼 수 있습니다.
  • 검색, 그룹, 고정, 좁은 보기로 계정이 많아도 깔끔하게 정리됩니다.
  • 지금 보고 있는 사이트의 계정을 먼저 알려 주고, 클릭·오른쪽 클릭·단축키로 코드를 넣습니다.
  • 고른 사이트에서는 코드 입력 칸 옆에 넣기 단추를 띄울 수 있습니다.

편한 방법으로 계정 추가

  • 지금 탭, 카메라, 이미지, 클립보드에서 QR 코드를 읽습니다.
  • otpauth:// 링크를 붙여 넣거나 비밀키를 직접 입력할 수 있습니다.
  • 여러 인증 앱의 평문 백업, 이동용 QR 코드, 표준 자격 증명 교환(CXF) 파일을 가져옵니다.
  • TOTP, HOTP, Steam, Battle.net 코드와 SHA-1·SHA-256·SHA-512, 6~10자리를 지원합니다.

안전한 보관

  • 계정은 기기 안의 암호화된 금고(AES-256-GCM)에 보관합니다.
  • 비밀번호(Argon2id), 복구 코드, 패스키 잠금 해제(파이어폭스 제외)로 잠글 수 있고, 자동 잠금 시점을 고를 수 있습니다.
  • 코드를 쓰기 전에 기기 인증을 요구하거나, 직접 정한 단축키로 코드를 가릴 수 있습니다.
  • 분석 도구·광고·개발자 서버가 없습니다. 소스 코드는 공개되어 있습니다.

백업과 복구

  • 암호화 백업, otpauth 텍스트·CXF·QR 코드로 내보내기를 지원합니다.
  • 브라우저 자체 동기화로 내 기기끼리 암호화해서 동기화합니다(크롬·엣지·파이어폭스).
  • 복구 스냅샷, 30일 휴지통, 계정 변경 기록을 제공합니다.
  • 컴퓨터 시계가 틀려 코드가 맞지 않을 때 시계 확인으로 알려 줍니다.

비밀키 대신 코드만 공유

앞으로 5~60분 동안의 코드만 보여 주는 링크를 보낼 수 있고, 비밀번호도 걸 수 있습니다. 링크에는 비밀키가 담기지 않습니다.

이용 가이드

  • 시작하기설치하고 첫 계정을 추가합니다.
  • 팝업·별도 창·사이드 패널코드를 여는 곳과 계정 목록 정리.
  • 로그인 화면에 코드 넣기클릭, 오른쪽 클릭, 단축키, 코드 칸 옆 단추.
  • 잠금과 보호비밀번호, 복구 코드, 패스키, 자동 잠금.
  • 백업·내보내기·동기화사본을 두고 다른 기기로 옮깁니다.
  • 링크로 코드 공유정한 시간 동안 코드만, 비밀키는 보내지 않습니다.
  • 문제 해결코드가 틀릴 때, 넣기가 안 될 때, 비밀번호를 잊었을 때.

다른 인증 앱에서 옮기시나요?

  • 기존 Authenticator 확장 프로그램에서백업 파일을 그대로 가져옵니다.
  • Authy 데스크톱과 다른 앱에서Google Authenticator, Aegis, 2FAS, Bitwarden 등.

개인정보

개발자 서버, 분석 도구, 광고가 없습니다. 시계 확인은 time.akamai.com, timeapi.io, cloudflare.com에 현재 시각만 묻고 계정 정보는 보내지 않으며, 끌 수 있습니다. 크롬·엣지·파이어폭스에서는 비밀번호 잠금을 설정하면 브라우저 동기화가 금고 키로 암호화한 계정을 브라우저 자체 동기화 서비스로 보내며, 끌 수 있습니다. 자세한 내용은 개인정보처리방침에 있습니다.

제한 사항

  • 클라우드 백업은 없습니다. 파일 백업과 브라우저 자체 동기화를 쓸 수 있습니다.
  • 패스키 잠금 해제는 파이어폭스에서 쓸 수 없습니다.
  • 사파리 버전은 macOS용이며 iOS 버전은 없습니다.
