잠금의 원리

잠금은 선택 기능입니다. 잠금 없이도 계정을 추가하고 코드를 넣을 수 있습니다. 잠금을 켜면 계정이 암호화된 금고(AES-256-GCM)에 저장됩니다. 무작위로 만든 금고 키가 금고를 열고, 이 키는 비밀번호·복구 코드·패스키가 각각 풀 수 있습니다.

비밀번호는 쓰기 전에 Argon2id로 일부러 느리게 변환합니다. 비밀번호를 추측해 보는 일을 어렵게 하려는 것입니다. 길고 여러 종류의 문자가 섞인 비밀번호일수록 추측하기 어렵습니다.

잠금 설정은 툴바 팝업에서 열 수 있습니다. 잠금이 꺼져 있으면 팝업의 잠금 단추가 "잠금 설정"으로 표시됩니다. 전체 화면에서 "잠금"을 골라도 됩니다.

잠금이 없으면 "잠금을 끄면 계정의 비밀키가 이 기기에 암호화되지 않은 채 저장됩니다." 다른 사람이 내 컴퓨터나 브라우저 프로필을 쓸 수 있다면 잠금을 켜 두세요.

비밀번호 잠금 켜기

  1. "잠금"을 엽니다. "금고 잠금 (선택)" 아래 "비밀번호 (8자 이상)"에 비밀번호를 입력합니다.
  2. "비밀번호 다시 입력"에 같은 비밀번호를 한 번 더 입력합니다.
  3. 강도 표시를 확인합니다. "약함", "보통", "강함" 중 하나가 나옵니다. 길이와 문자 종류(소문자·대문자·숫자·기호)로 정하며, "강함"은 12자 이상에 3종류 이상일 때입니다.
  4. "잠금 켜기"를 누릅니다.
  5. 나타나는 복구 코드를 보관합니다(다음 절).

8자보다 짧으면 "비밀번호는 8자 이상이어야 합니다."가, 두 칸이 다르면 "두 비밀번호가 다릅니다."가 나옵니다. 강도 표시는 참고용이며 8자 이상만 필수입니다. 관리자가 비밀번호 규칙을 정했다면 "관리자 비밀번호 규칙에 맞지 않습니다."가 나올 수도 있습니다.

1.0.0에서는 잠금을 켜도 잠금이 꺼져 있을 때 저장된 스냅샷은 보호되지 않은 채 남습니다. 브라우저 프로필에 접근할 수 있는 사람은 그 이전 스냅샷의 비밀키를 읽을 수 있습니다.

1.0.1 1.0.1부터 잠금을 켜면 이전 스냅샷도 함께 다시 암호화합니다.

브라우저 동기화가 켜져 있으면 잠금을 켠 뒤 계정이 암호화되어 다른 기기로 동기화됩니다. 설정 → 동기화에서 바꿀 수 있습니다. 자세한 내용은 백업·내보내기·동기화를 보세요.

복구 코드 보관하기

복구 코드는 비밀번호를 잊었을 때 금고를 여는 코드입니다. 잠금을 켠 직후 한 번만 보여 줍니다.

  1. "복사"를 누르거나 "텍스트 파일로 저장"을 눌러 안전한 곳에 보관합니다. 종이에 적어도 됩니다.
  2. "복구 코드를 다시 입력해 주세요." 칸에 코드를 다시 입력하고 "확인"을 누릅니다. 띄어쓰기, 하이픈, 대소문자는 구분하지 않습니다.

코드가 다르면 "코드가 다릅니다. 다시 확인해 주세요."가 나옵니다.

1.0.1 1.0.1부터 툴바 팝업에서는 "텍스트 파일로 저장"이 보이지 않습니다. 저장 창이 뜨면 팝업이 닫히기 때문입니다. 팝업에서는 "복사"를 쓰거나, 전체 화면을 열어 파일로 저장하세요.

코드를 바꾸려면 "잠금"에서 "새 복구 코드 만들기"를 누릅니다. 현재 비밀번호를 입력하고 새 코드를 확인하면 됩니다. "새 복구 코드를 만들면 기존 복구 코드는 더 이상 사용할 수 없습니다."

잠금 해제

금고가 잠기면 팝업에 "잠금 상태"가 표시됩니다.

  • 비밀번호: 입력하고 "잠금 해제"를 누릅니다. 틀리면 "비밀번호가 맞지 않습니다."가 나옵니다.
  • 복구 코드: "복구 코드로 잠금 해제"를 누르고 코드를 입력합니다. 틀리면 "복구 코드가 맞지 않습니다."가 나옵니다. "비밀번호로 잠금 해제"를 누르면 돌아갑니다.
  • 패스키: "패스키로 잠금 해제"를 누릅니다(아래 참고).

복구 코드로 잠금을 풀면 새 코드가 나옵니다. "사용한 복구 코드는 더 이상 쓸 수 없습니다. 새 복구 코드를 안전한 곳에 저장해 주세요." 안내에 따라 "복사"로 보관한 뒤 "보관 완료"를 누르세요.

1.0.1 1.0.1부터는 방금 쓴 코드가 "보관 완료"로 새 코드를 확인할 때까지 계속 쓸 수 있습니다.

패스키로 잠금 해제

패스키를 등록하면 비밀번호를 입력하는 대신 기기(지문·얼굴·보안 키 등, 기기와 브라우저에 따라 다름)로 잠금을 풀 수 있습니다.

  1. 먼저 비밀번호로 잠금을 해제합니다. 그렇지 않으면 "먼저 비밀번호로 잠금을 해제해 주세요."가 나옵니다.
  2. "잠금" → "패스키"에서 "패스키 추가"를 누릅니다.
  3. 브라우저 창에서 확인합니다("패스키 창에서 확인해 주세요.").

삭제하려면 현재 비밀번호를 입력하고 해당 패스키 옆의 "삭제"를 누릅니다.

  • Firefox: 지원하지 않습니다. "Firefox에서는 이 확장의 패스키 잠금 해제와 코드 넣기 인증을 지원하지 않습니다. 비밀번호와 복구 코드로 금고를 열 수 있습니다."라고 안내합니다.
  • 그 밖의 브라우저: 브라우저가 필요한 WebAuthn PRF 기능을 지원하는지 확인합니다. 지원하지 않으면 "패스키 추가"가 나타나지 않거나 "이 기기나 브라우저에서는 패스키를 쓸 수 없습니다." 또는 "이 패스키는 잠금 해제에 필요한 기능(PRF)을 지원하지 않습니다."가 나옵니다.

패스키는 비밀번호와 복구 코드를 대신하지 않습니다. 둘 다 보관하세요.

자동 잠금과 "지금 잠그기"

잠금 설정의 "지금 잠그기"나 팝업 툴바의 잠금 단추를 누르면 바로 잠깁니다. "자동 잠금"에서는 저절로 잠기는 시점을 고릅니다. 기본값은 15분입니다.

  • "인증 도구 화면을 모두 닫을 때"
  • "5분 동안 사용하지 않으면", "15분 동안 사용하지 않으면", "60분 동안 사용하지 않으면"
  • "직접 입력": "분 (1~1440)"을 입력합니다.
  • "자동 잠금 안 함": "직접 잠그기 전까지 잠금 해제 상태를 유지합니다. 브라우저를 완전히 종료하면 잠깁니다."

관리자가 시간을 정했다면 관리자가 정한 값이라는 안내가 보이고, 직접 바꿀 수 없습니다.

1.0.1 1.0.1부터 별도 창이나 사이드 패널이 열려 있어도 자동 잠금이 제때 작동합니다. QR 캡처 화면도 "인증 도구 화면을 모두 닫을 때"의 열린 화면으로 셉니다.

코드 넣기 전 추가 인증

선택 기능입니다. 켜면 코드를 페이지에 넣을 때마다 등록한 기기로 확인합니다. 코드 표시와 복사는 그대로 쓸 수 있습니다. 꺼져 있을 때는 "금고가 열려 있으면 비밀번호나 패스키 확인 없이 코드를 넣습니다."

  1. 비밀번호 잠금을 켜고 복구 코드를 보관합니다.
  2. 패스키를 등록합니다. 또는 "잠금" → "코드 넣기 추가 인증 (선택)" → "추가 인증 설정"에서 안내를 따릅니다. "복구 코드를 안전한 곳에 보관했습니다."에 체크하고 "기기 등록으로 계속"을 누릅니다.
  3. "코드 넣을 때 기기 인증"을 켭니다. "코드 넣기 인증을 켰습니다."가 나옵니다.

끄려면 같은 스위치를 쓰고 기기로 확인합니다. 기기를 잃어버렸다면 "기기 인증을 사용할 수 없나요?"를 열고 비밀번호를 입력한 뒤 "비밀번호로 코드 넣기 인증 끄기"를 누르세요. 금고 잠금은 유지됩니다. 잠금을 끄거나 마지막 패스키를 삭제하려면 먼저 이 기능을 꺼야 합니다. Firefox에서는 쓸 수 없습니다.

화면에서 코드 가리기

"코드 가리기·보이기"를 쓰면 팝업의 모든 코드가 점으로 가려집니다. 화면을 공유하기 전에 쓰세요. 팝업에 "코드를 가리고 있습니다."가 표시되고, 열려 있던 공유 창은 닫힙니다.

기본 단축키는 없습니다. 브라우저의 확장 프로그램 단축키 설정 화면에서 "코드 가리기·보이기"에 키를 지정하세요. 설정 화면은 브라우저의 확장 프로그램 메뉴에서 열 수 있습니다. 코드 넣기 단축키는 Ctrl+Shift+Y(맥은 Command+Shift+Y)입니다. 팝업이 열려 있을 때는 Alt+Shift+H로도 가리거나 보일 수 있습니다. 가린 상태는 브라우저를 켜 둔 동안만 유지됩니다.

비밀번호 변경·잠금 끄기

  • 변경: "잠금" → "비밀번호 변경". 현재 비밀번호를 입력하고 새 비밀번호를 두 번 입력한 뒤 "비밀번호 변경"을 누릅니다. "비밀번호를 변경했습니다."가 나옵니다. 복구 코드는 그대로입니다.
  • 끄기: "잠금" → "잠금 끄기". 경고를 읽고 "암호화 없이 저장되는 위험을 이해했습니다."에 체크한 뒤 비밀번호를 입력하고 "잠금 끄기"를 누릅니다. 관리자가 비밀번호를 필수로 정했다면 이 항목은 보이지 않습니다.

비밀번호를 잊었다면

  1. 복구 코드나 등록한 패스키로 잠금을 풉니다. 이렇게 계속 계정을 쓸 수 있고, 복구 코드로 풀 때마다 새 복구 코드가 나오니 보관해 주세요.
  2. 1.0.0에서는 "비밀번호 변경", "잠금 끄기", 내보내기가 현재 비밀번호를 묻기 때문에, 잊은 비밀번호를 재설정할 수는 없습니다.
  3. 비밀번호, 복구 코드, 쓸 수 있는 패스키가 모두 없다면 금고를 열 수 없고, Popout이 비밀번호를 대신 초기화해 줄 수도 없습니다.
  4. 이때는 백업 파일이 있으면 그것으로 복원하거나, 각 서비스에서 계정을 다시 등록해야 합니다. 초기화하면 이 브라우저에 저장된 내용이 모두 지워지니 먼저 원시 사본을 저장하세요(백업·내보내기·동기화 참고).

복구 코드와 백업 파일은 필요해지기 전에 미리 보관해 두세요.

삭제한 계정과 휴지통

계정을 삭제하면 "이 계정을 휴지통으로 옮길까요? 30일 뒤 영구 삭제됩니다."라는 확인이 나옵니다. "휴지통으로 이동"을 고르세요. "휴지통"에서는 항목마다 남은 일수를 볼 수 있습니다. "복원"으로 되살리고, "영구 삭제"로 지우고, "휴지통 비우기"로 모두 비웁니다. 자세한 내용은 백업과 복구를, 문제가 있으면 문제 해결을 보세요.

평가 남기기 쓰는 브라우저의 스토어에 남긴 짧은 평가가 다른 사람이 Popout을 찾는 데 도움이 됩니다.
