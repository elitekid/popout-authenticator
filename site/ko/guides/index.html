이용 가이드

기능별로 단계를 나눠 설명합니다. 지금 스토어에 있는 1.0.0 기준이며, 1.0.1에서 바뀌는 부분은 따로 표시했습니다.

기능별 가이드

  • 시작하기: 설치와 첫 계정 추가Popout Authenticator를 설치하고 QR 코드·링크·직접 입력으로 계정을 추가합니다.
  • 팝업·별도 창·사이드 패널툴바 팝업, 별도 창, 사이드 패널에서 코드를 보고, 검색·그룹·고정으로 계정 목록을 정리합니다.
  • 로그인 화면에 코드 넣기허용한 사이트에서 클릭, 오른쪽 클릭 메뉴, 단축키, 코드 칸 옆 단추로 코드를 넣습니다.
  • 잠금과 보호비밀번호 잠금, 복구 코드, 패스키 잠금 해제, 자동 잠금, 화면 공유 중 코드 가리기를 설정합니다.
  • 백업·내보내기·동기화암호화 백업을 만들고, 다른 앱용으로 내보내고, 복구 스냅샷과 휴지통에서 되살리고, 기기 사이에 동기화합니다.
  • 링크로 코드 공유정한 시간 동안 코드만 보여 주는 링크를 보냅니다. 비밀번호를 걸 수 있고, 링크에는 비밀키가 담기지 않습니다.
  • 팀원에게 2FA 코드를 보내야 할 때: 임시 링크의 사용법과 한계개인별 접근·공유 금고·임시 코드 링크 중 무엇을 쓸지 고르고, 링크로 할 수 없는 일을 확인합니다.
  • 브라우저 2FA 확장 비교Popout Authenticator, Authenticator, 2FAS, 2FA Authenticator의 코드 생성 위치·보관·백업·가져오기·자동 넣기를 출처와 함께 나란히 봅니다.
  • 문제 해결코드가 맞지 않을 때, 코드 넣기가 안 될 때, 잠금이 풀리지 않을 때, 가져오기가 안 될 때 확인할 것.

다른 인증 앱에서 옮기시나요?

  • 기존 Authenticator 확장 프로그램에서 옮기기백업 파일을 그대로 가져옵니다.
  • Authy 데스크톱과 다른 앱에서 옮기기Google Authenticator, Aegis, 2FAS, Bitwarden 등.
  • 구글 OTP 코드를 PC 브라우저로 옮기기휴대폰 앱에서 QR 코드를 내보내 웹캠·사진·화면으로 Popout에 읽어 옵니다.

IT 관리자용

  • IT 관리자 배포 안내크롬·엣지·파이어폭스에 확장 프로그램을 강제 설치하고 관리 정책 키를 설정합니다.

평가 남기기 쓰는 브라우저의 스토어에 남긴 짧은 평가가 다른 사람이 Popout을 찾는 데 도움이 됩니다.
