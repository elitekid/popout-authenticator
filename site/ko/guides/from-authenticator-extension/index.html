기존 Authenticator 확장 프로그램에서 옮기기

기존 "Authenticator" 확장 프로그램의 GitHub 최신 릴리스는 v8.0.2(2024-09-15)입니다. 릴리스 페이지(2026-10-15 확인)를 참고해 주세요. Popout Authenticator는 이 확장 프로그램의 백업을 바로 읽을 수 있고, 기존 확장 프로그램의 MIT 라이선스 코드를 바탕으로 만들었습니다.

Popout Authenticator 설치

순서

  1. 기존 확장 프로그램에서 설정 → 백업으로 가서 "백업 파일 다운로드" 또는 "비밀번호로 보호된 백업 다운로드"를 누릅니다. (메뉴 이름은 v8.0.2 소스 기준이며, 다른 버전은 다를 수 있습니다.)

    • "백업 파일 다운로드"는 암호화하지 않은 백업입니다. authenticator.txt로 저장되며, Steam이나 Battle.net 계정이 있으면 authenticator.json으로 저장됩니다.
    • "비밀번호로 보호된 백업 다운로드"는 암호화된 authenticator.json으로 저장됩니다. 이 단추는 설정 → 보안에서 비밀번호를 정한 뒤에 나타납니다.
  2. 위 단추로 Popout Authenticator를 설치합니다.
  3. Popout에서 + → "계정 추가" → "백업 파일" 탭 → "백업 파일을 골라 주세요."를 누릅니다. 툴바 팝업에서는 파일을 고르는 작은 창이 열립니다.
  4. 암호화된 백업이면 "암호화된 백업입니다. 비밀번호를 입력해 주세요."라고 묻습니다. "백업 비밀번호"에 기존 확장 프로그램에서 정한 비밀번호를 입력하고 "확인"을 누릅니다. 비밀번호가 틀리면 "비밀번호가 맞지 않습니다."라고 알려 줍니다.
  5. 결과 메시지에 추가된 계정 수가 표시됩니다. 이미 있는 계정(종류와 비밀키가 같은 계정)은 건너뛰며, 기존 계정을 덮어쓰지 않습니다.

  6. 옮긴 뒤에는 다음을 해 주세요.

    • 무엇이든 지우기 전에 두 확장 프로그램에서 코드가 같은지 확인합니다.
    • 암호화하지 않은 백업이었다면 내려받은 파일을 지웁니다. 파일에 비밀키가 들어 있습니다.
    • Popout에 비밀번호를 설정하는 것을 고려해 주세요.

아주 오래된 버전의 기존 확장 프로그램에서 만든 암호화 백업은 열리지 않을 수 있습니다. 그럴 때는 암호화하지 않은 백업을 다시 내려받아 주세요.
