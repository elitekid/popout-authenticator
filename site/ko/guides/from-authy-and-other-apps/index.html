Authy 데스크톱과 다른 앱에서 옮기기

쓰는 앱에 맞는 부분을 봐 주세요. 기존 Authenticator 확장 프로그램은 별도 가이드가 있습니다.

Popout Authenticator 설치

Authy

Twilio는 2024-03-19에 Authy 데스크톱(Windows, macOS, Linux)을 종료했습니다 — Twilio 종료 안내(2026-10-15 확인). Authy는 토큰 내보내기를 제공하지 않습니다 — Export or Import Tokens in the Authy app(2026-10-15 확인).

그래서 계정마다 다시 설정해야 합니다.

  1. 서비스마다 로그인한 뒤 2단계 인증 설정을 엽니다.
  2. 인증 앱을 다시 설정합니다. 서비스가 새 QR 코드를 보여 줍니다.
  3. Popout에서 새 QR 코드를 추가합니다. + → "화면에서 QR 코드 읽기"를 누르거나, + → "계정 추가" → "QR 코드" 탭을 사용합니다.
  4. 모든 계정이 Popout에서 동작할 때까지 Authy를 지우지 마세요.

이전에 내보낸 otpauth:// 링크 JSON 목록이 있다면 "백업 파일"로 Popout에서 읽을 수 있습니다.

Google Authenticator

  1. 휴대폰 앱에서 Menu → Transfer codes → Export codes를 엽니다. (영어 앱 기준 메뉴 이름이며, 한국어 이름은 확인하지 못했습니다. Google 안내, 2026-10-15 확인)
  2. 잠금을 풀고 계정을 선택한 뒤 Next를 누릅니다. QR 코드가 한 개 이상 나타납니다.
  3. Popout에서 + → "카메라로 QR 코드 읽기"를 누르거나, + → "계정 추가" → "QR 코드" → "QR 코드 이미지 선택"을 사용합니다. 이미지를 여러 개 한꺼번에 고를 수 있습니다.
  4. QR 코드가 여러 개이면 하나씩 모두 읽어 주세요.

이 QR 코드에는 비밀키가 들어 있습니다. 다른 사람에게 보내지 말고, 캡처나 사진은 끝난 뒤 지워 주세요.

다른 앱

표에 따로 적지 않았으면 암호화하지 않은 내보내기 파일을 써 주세요. Aegis·2FAS·Bitwarden의 암호화된 파일이면 Popout이 그 앱에서 암호화 없이 내보낸 파일을 쓰라고 알려 줍니다(예: "Aegis 앱에서 암호화 없이 내보낸 파일을 써 주세요.").

앱내보낼 것참고
Aegis암호화하지 않은 금고 내보내기(JSON)암호화된 내보내기는 지원하지 않습니다.
2FAS2FAS Backup → Export, 비밀번호 설정 없이 (2FAS 안내, 2026-10-15 확인)파일 이름이 .2fas로 끝납니다. 파일 선택 창에서 고를 수 없으면 파일 이름 끝을 .json으로 바꿔 주세요. 1.0.1부터는 .2fas 파일도 고를 수 있습니다.
Bitwarden AuthenticatorSettings → Export → file format .json → Export items (Bitwarden 안내, 2026-10-15 확인)CSV는 지원하지 않습니다. 암호화하지 않은 Bitwarden 비밀번호 관리자 JSON 내보내기도 읽을 수 있습니다(TOTP 필드를 읽습니다).
FreeOTP+JSON 내보내기, 또는 otpauth:// 링크가 담긴 텍스트 파일
andOTP암호화하지 않은 JSON 백업암호화된 백업은 지원하지 않습니다.
RaivoSettings → Export OTPs to ZIP archive (Bitwarden 안내 기준, 2026-10-15 확인)정해 둔 비밀번호로 ZIP 파일을 풀고 raivo-otp-export.json을 가져옵니다. Popout은 ZIP 파일을 직접 열 수 없습니다.
2FA Authenticator (authenticator.sh)백업 파일(암호화 여부 상관없음)암호화된 파일이면 Popout이 비밀번호를 묻습니다.
그 밖의 앱한 줄에 otpauth:// 또는 otpauth-migration:// 링크 하나씩 적은 .txt 파일"링크" 탭에 링크를 붙여 넣어도 됩니다.

Popout으로 가져오기

  1. Popout에서 + → "계정 추가" → "백업 파일" 탭 → "백업 파일을 골라 주세요."를 누릅니다. 툴바 팝업에서는 파일을 고르는 작은 창이 열립니다.
  2. 2FA Authenticator의 암호화된 백업이면 "암호화된 백업입니다. 비밀번호를 입력해 주세요."라고 묻습니다. "백업 비밀번호"에 입력하고 "확인"을 누릅니다. 비밀번호가 틀리면 "비밀번호가 맞지 않습니다."라고 알려 줍니다.
  3. 결과 메시지에 추가된 계정 수가 표시됩니다. 이미 있는 계정(종류와 비밀키가 같은 계정)은 건너뛰며, 기존 계정을 덮어쓰지 않습니다.

파일을 인식하지 못하면 "알 수 없는 형식입니다."라고 표시됩니다.

옮긴 뒤

  • 무엇이든 지우기 전에 두 앱에서 코드가 같은지 확인합니다.
  • 암호화하지 않은 내보내기 파일은 지워 주세요. 파일에 비밀키가 들어 있습니다.
