Popout Authenticator
홈 가이드 GitHub English
홈 › 가이드

IT 관리자 배포 안내

회사나 학교에서 기존 Authenticator 확장 프로그램(authenticator.cc)을 관리 정책으로 배포했거나 배포하려는 관리자를 위한 쪽입니다. Popout Authenticator는 같은 이름의 정책 키를 읽습니다. 기존 값을 쓰기 전에 아래 표에서 키마다 동작을 확인해 주세요.

정책 키

Popout은 브라우저의 관리 저장소(managed_schema.json에 선언)에서 아래 8개 키를 읽습니다. 키 이름은 기존 확장 프로그램의 스키마와 같습니다. 기존 확장 프로그램의 disableInstallHelp 키는 받지 않습니다.

키형식동작
storageArea문자열: sync 또는 local브라우저 동기화를 강제로 켜거나(sync) 끕니다(local). 어느 쪽이든 주 저장은 local입니다. 동기화 설정은 사용자가 바꿀 수 없게 잠깁니다. 다른 값은 무시합니다.
disableBackup불리언값을 읽어 두지만, 현재 코드는 이 값으로 화면을 숨기지 않습니다.
disableExport불리언true이면 백업 화면에서 내보내기 대신 안내 문구가 나오고, 원시 사본 저장과 팝업의 계정별 내보내기가 숨겨집니다.
enforcePassword불리언true이면 비밀번호 잠금이 없는 사용자에게 비밀번호 설정을 요구합니다. 잠금을 켜기 전에는 계정 추가와 원시 사본 가져오기가 막히고, 사용자는 잠금을 끌 수 없습니다.
enforceAutolock숫자(분)자동 잠금 시간을 정하고 사용자가 바꿀 수 없게 잠급니다. 0 이하는 무시하고, 1440(24시간)을 넘으면 1440으로 맞춥니다.
passwordPolicy문자열(정규식)새 비밀번호가 이 정규식과 맞아야 합니다. 빈 값이나 잘못된 정규식은 무시합니다.
passwordPolicyHint문자열비밀번호가 passwordPolicy와 맞지 않을 때 보여 주는 문구입니다.
feedbackURL문자열(http 또는 https 주소)설정의 의견 보내기 링크 주소를 바꿉니다. 다른 방식의 주소나 잘못된 주소는 무시합니다.

정책은 페이지마다 한 번 읽고, 정책이 바뀌면 다시 읽습니다. 읽는 데 1초를 넘기거나 실패하면 그 읽기에서는 정책이 없는 것으로 봅니다.

정책에 비밀키를 넣어 계정을 일괄 배포하는 기능은 없습니다.

정책 값 전달

아래 값은 설명용 가짜 예시입니다. <ID>는 쓰는 브라우저의 확장 ID로 바꿔 주세요.

윈도 레지스트리(크롬)

아래 경로 밑에 policy 키를 만들고 정책 키마다 값을 하나씩 추가합니다(문자열은 REG_SZ, 숫자와 불리언은 REG_DWORD).

HKLM\Software\Policies\Google\Chrome\3rdparty\extensions\<ID>\policy

맥(크롬)

이름이 com.google.Chrome.extensions.<ID>인 plist를 씁니다.

<?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0">
<dict>
  <key>enforcePassword</key>
  <true/>
  <key>enforceAutolock</key>
  <integer>15</integer>
  <key>passwordPolicy</key>
  <string>^.{12,}$</string>
</dict>
</plist>

파이어폭스(policies.json)

Popout의 파이어폭스판도 같은 관리 스키마를 선언하고 storage.managed로 읽습니다.

{
  "policies": {
    "3rdparty": {
      "Extensions": {
        "popout-authenticator@elitekid": {
          "enforcePassword": true,
          "enforceAutolock": 15,
          "passwordPolicy": "^.{12,}$",
          "passwordPolicyHint": "12자 이상으로 정해 주세요."
        }
      }
    }
  }
}

사용자 계정 옮기기

사용자는 기존 확장 프로그램의 백업 파일로 계정을 옮길 수 있습니다. 기존 Authenticator 확장 프로그램에서 옮기기를 참고해 주세요.
