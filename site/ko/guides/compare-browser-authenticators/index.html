확인 방법

이 쪽은 Popout Authenticator 개발자가 썼습니다. 이 점을 감안해 읽어 주세요. 다른 확장의 값은 모두 그 확장의 스토어·웹사이트·문서·소스 코드에서 가져왔고, 출처에 적었습니다. "확인 못 함"은 그 자료에서 찾지 못했다는 뜻이지 기능이 없다는 뜻이 아닙니다. 다른 확장을 설치해 시험하지는 않았습니다. 틀리거나 오래된 내용이 있으면 이슈로 알려 주세요.

필요에 맞는 선택

  • 비밀키를 휴대폰에만 두고 싶다면. 2FAS는 비밀키를 휴대폰 앱에 두고, 코드마다 휴대폰에서 승인하게 합니다. 브라우저에는 비밀키가 남지 않습니다.
  • 휴대폰 없이 브라우저에서 모두 하고 싶다면. Authenticator, 2FA Authenticator, Popout 모두 브라우저에서 코드를 만듭니다. 어느 것을 쓰든 비밀번호를 정하세요. 비밀번호 관리자와 인증 코드를 한 컴퓨터에 함께 두는 데에는 대가가 있습니다. 중요한 계정은 휴대폰 앱이나 보안 키로 인증 수단을 나누는 편이 안전합니다.
  • 이미 Authenticator를 쓰고 있다면. 지금도 동작합니다. 크롬 스토어 마지막 업데이트는 2024년 8월 27일입니다. 옮긴다면 그 백업 파일(비밀번호 걸린 것 포함)을 Popout이 읽습니다. 기존 Authenticator 확장 프로그램에서 옮기기를 보세요.
  • 사이드 패널이나 계속 떠 있는 별도 창에서 보고 싶다면. Popout과 2FA Authenticator 둘 다 됩니다.

Popout의 한계

  • 개발자가 운영하는 클라우드 백업은 없습니다. 백업은 직접 보관하는 파일이고, 동기화는 브라우저 자체 동기화를 씁니다.
  • 파이어폭스에서는 패스키 잠금 해제와 기기 인증을 쓸 수 없습니다.
  • 사파리판은 macOS 전용이고 아직 심사 중입니다.
  • 영어와 한국어 외의 화면 언어는 기계 번역입니다.
  • Popout은 새 프로젝트입니다. 1.0.0을 2026년 10월에 냈습니다.

출처

모두 2026년 10월 18일에 확인했습니다.

  • Authenticator: Chrome Web Store, Firefox Add-ons, GitHub, 내보내기·가져오기, 표준 백업 형식, 개인정보처리방침
  • 2FAS Auth: Chrome Web Store, 확장 동작 방식, 지원 브라우저, 토큰 저장 위치, 앱 사용 설명, GitHub
  • 2FA Authenticator: Chrome Web Store, 동작 방식, FAQ, GitHub
  • Popout Authenticator: GitHub, 개인정보처리방침

관련 가이드

  • 기존 Authenticator 확장 프로그램에서 옮기기: 비밀번호 걸린 백업 파일도 읽습니다.
  • Authy 데스크톱과 다른 앱에서 옮기기: Popout이 읽는 형식을 확인합니다.
  • 잠금과 보호: 비밀번호와 자동 잠금을 정합니다.

평가 남기기 쓰는 브라우저의 스토어에 남긴 짧은 평가가 다른 사람이 Popout을 찾는 데 도움이 됩니다.
