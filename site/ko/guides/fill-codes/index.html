코드 넣기가 동작하는 방식

Popout은 지금 보고 있는 페이지의 코드 칸에 현재 코드를 넣습니다. 넣기는 항상 직접 시작하며, 방법은 네 가지입니다.

방법시작하는 곳계정을 고르는 쪽
팝업추천 계정 옆 "넣기", 또는 계정 메뉴의 "이 페이지에 넣기"사용자
오른쪽 클릭 메뉴입력칸에서 오른쪽 클릭 → "인증 코드 넣기"Popout (지정한 사이트 기준)
단축키Ctrl+Shift+Y (맥: Command+Shift+Y)Popout (지정한 사이트 기준)
칸 옆 단추코드 칸 옆의 "코드 넣기" 단추Popout (단추를 켠 계정 기준)

페이지를 열었다고 저절로 넣지는 않습니다. 코드 넣기에는 금고 잠금이나 패스키가 필요하지 않습니다. 계정을 추가하면 바로 쓸 수 있습니다.

허용한 사이트

"허용"에는 서로 다른 두 가지가 있습니다.

계정에 지정한 사이트

계정마다 사이트 주소(예: example.com)를 지정할 수 있습니다. 지정한 주소의 하위 도메인도 같은 사이트로 봅니다. 그 계정에 지정한 사이트에서만 코드를 넣고 자동으로 확인합니다.

  • 직접 추가하려면 계정의 "⋯" 메뉴 → "편집"에서 "사이트 주소 (쉼표 또는 줄바꿈으로 구분)"에 주소를 적고 "저장"을 누릅니다.
  • 지정하지 않은 사이트에서 코드를 복사하면 "example.com에서 사용할 계정으로 기억할까요?"처럼 묻습니다(지금 보고 있는 사이트 이름이 들어갑니다). "기억"을 누르면 저장하고, "아니요"를 누르면 저장하지 않습니다.
  • 지정하지 않은 사이트에 넣으려 하면 먼저 확인합니다. "기억하고 넣기", "이번만 넣기", "취소" 중에서 고릅니다. "이번만 넣기"는 넣기만 하고 자동 확인은 하지 않습니다.

브라우저의 사이트 접근 권한

Popout은 모든 웹사이트에 대한 접근 권한을 계속 갖지 않습니다. 권한은 다음 경우에 생깁니다.

  • 툴바 아이콘을 누르거나, 오른쪽 클릭 항목을 쓰거나, 단축키를 누르면 그 탭에서 그 동작을 하는 동안만 접근할 수 있습니다.
  • 별도 창이나 사이드 패널에서는 브라우저가 사이트별 허용을 요구할 수 있습니다. 이때 "example.com에서 넣기 허용" 같은 단추가 나타납니다. 허용하지 않으면 "사이트 접근을 허용하지 않아 코드를 넣지 않았습니다."라고 알려 줍니다.
  • 칸 옆 단추는 단추를 켠 사이트의 접근 권한을 요청합니다(아래 참고).

자동 확인은 기본으로 켜져 있습니다. 끄려면 설정 → "복사 및 개인정보" → "코드를 넣은 뒤 자동으로 확인"을 해제하세요. 코드만 입력하는 폼에 확인 단추가 하나일 때만 누르고, 지정한 사이트에서만 동작합니다. "이번만 넣기"나 복사할 때 넣기에는 적용하지 않습니다.

팝업에서 넣기

  1. 로그인 페이지를 열고 코드 칸이 나타날 때까지 기다립니다.
  2. 툴바의 Popout 아이콘을 누릅니다. 사이트에 맞는 계정 옆에 "넣기" 단추가 보입니다.
  3. "넣기"를 누릅니다. 성공하면 "코드를 넣었습니다."라고 알리고 팝업이 닫힙니다.

"넣기"가 보이지 않으면 원하는 계정의 "⋯" 메뉴에서 "이 페이지에 넣기"를 고르세요. 추천은 설정의 "사이트에 맞는 계정 추천 (끄면 사이트 사용 기록 삭제)"에서 끌 수 있습니다.

별도 창이나 사이드 패널에서 계정 줄의 단추를 쓰려면 선택 권한인 탭 권한이 필요합니다. "현재 탭에 맞춰 추천 계정도 바뀌도록 허용할까요?"라고 물으면 "허용"이나 "닫기"를 고릅니다. 허용하지 않았다면 메뉴의 "이 페이지에 넣기"를 쓰세요. 자세한 내용은 팝업·별도 창·사이드 패널을 보세요.

1.0.1 1.0.1부터 브라우저의 사이트 접근 창 때문에 팝업이 닫혀도 넣기가 끝까지 이어집니다.

오른쪽 클릭 메뉴로 넣기

  1. 페이지의 코드 칸에서 오른쪽 클릭합니다.
  2. "인증 코드 넣기"를 고릅니다.

지정한 사이트가 지금 페이지와 맞는 계정을 고릅니다. 여럿이 맞으면 그 사이트에서 가장 자주 넣은 계정을 씁니다. 하나로 정하지 못하면 넣지 않고, 팝업을 열거나 페이지에 "계정을 골라 주세요."라고 표시합니다.

1.0.1 1.0.1부터 Firefox에서는 비밀번호 형태의 코드 칸에서도 이 메뉴가 나타나고, 별도 창에서도 넣기가 동작합니다.

단축키로 넣기

Ctrl+Shift+Y(맥은 Command+Shift+Y)를 누르면 "이 페이지에 인증 코드 넣기"가 실행됩니다. 오른쪽 클릭 메뉴와 같은 방식이며, 먼저 코드 칸을 눌러 두세요.

"사이트에 맞는 계정의 코드 넣기"라는 명령도 있습니다. 기본 단축키는 없고 같은 동작을 합니다.

단축키 바꾸기

  • Chrome: chrome://extensions/shortcuts를 엽니다.
  • Edge: edge://extensions/shortcuts를 엽니다.
  • Firefox: 부가 기능 관리 쪽에서 톱니 아이콘을 누르고 "Manage Extension Shortcuts"를 고릅니다.

목록에서 Popout Authenticator를 찾아 원하는 키를 지정하세요.

코드 칸 옆 단추

정해 둔 사이트에서는 코드 칸 옆에 작은 "코드 넣기" 단추가 나타납니다. 단추를 눌러야 넣으며, 저절로 넣지는 않습니다. 한 페이지에는 단추를 최대 세 개까지 표시합니다.

계정 하나에 켜기

  1. 계정의 "⋯" 메뉴 → "편집"을 엽니다.
  2. "사이트 주소 (쉼표 또는 줄바꿈으로 구분)"에 사이트를 적습니다. 예: github.com
  3. "직접 지정한 사이트에서 코드 넣기"를 켭니다.
  4. "저장"을 누르고 브라우저가 묻는 사이트 접근 권한을 허용합니다. 허용하지 않으면 "사이트 접근 권한을 얻지 못해 단추를 켜지 않았습니다."라고 알려 줍니다.

알려진 서비스에 켜기

설정 → "사이트에서 코드 넣기"에서 "알려진 서비스 자동 인식"을 켭니다. GitHub, GitLab, Google, Cloudflare, Dropbox, JetBrains가 대상이며, 서비스 이름으로 계정을 찾습니다. 툴바 팝업에서는 권한 요청을 위해 설정이 작은 창으로 열립니다.

끄기

계정을 편집해 "직접 지정한 사이트에서 코드 넣기"를 끄고 "저장"을 누릅니다. 알려진 서비스는 "알려진 서비스 자동 인식"을 끕니다. 다른 계정이 쓰지 않는 사이트 접근 권한은 함께 놓아 줍니다.

1.0.1 1.0.1부터 단추가 칸의 가운데에 맞춰지고, 페이지 내용이 칸을 아래로 밀면 따라 움직입니다.

넣는 대신 복사하기

팝업에서 계정을 누르면 코드가 복사됩니다. 시간 기반 계정은 메뉴의 "다음 코드 복사"로 다음 코드를 복사할 수 있습니다.

  • 설정 → "복사 및 개인정보" → "복사한 뒤 클립보드 지우기"를 켜면 복사하고 30초 뒤, 그사이 다른 것을 복사하지 않았을 때 클립보드를 비웁니다. 선택 권한인 클립보드 읽기 권한이 필요하며, Safari에서는 지원하지 않습니다.
  • "코드를 복사할 때 입력칸에도 넣기"를 켜면 복사하면서 페이지에도 넣습니다. 자동 확인은 하지 않습니다.

넣을 칸을 찾지 못하면 코드를 복사하고 페이지에 "코드를 복사했습니다. 입력칸에 붙여 넣어 주세요."라고 표시합니다.

1.0.1 1.0.1부터 넣기에 실패해 복사된 코드도, 해당 설정을 켰다면 클립보드에서 지워집니다.

기기 인증

코드를 넣을 때마다 등록한 기기(지문, PIN 등)로 확인하게 할 수 있습니다. 기본은 꺼져 있고 Firefox에서는 쓸 수 없습니다. 설정 방법은 잠금과 보호를 보세요.

HOTP, Steam, Battle.net

  • HOTP: 넣을 때마다 카운터가 1 올라가고 그 코드를 씁니다. 로그인 한 번에 한 번만 넣으세요.
  • Steam과 Battle.net 계정은 시간 기반 계정처럼 넣습니다.
  • 시간 기반 코드가 2초 안팎으로 남았으면 다음 코드가 나올 때까지 기다린 뒤 넣습니다.

넣을 수 없는 곳

  • https가 아닌 페이지: "보안 연결(https)이 아닌 페이지에는 코드를 넣지 않습니다."라고 알려 줍니다. 이 기기의 시험 주소(localhost, 127.0.0.1)는 허용합니다.
  • 브라우저 내부 페이지나 확장 스토어 같은 곳: "이 페이지에는 코드를 넣을 수 없습니다. 인증할 사이트에서 다시 눌러 주세요."라고 알려 줍니다.
  • 다른 사이트의 프레임: 프레임 자체의 주소가 계정에 지정한 사이트여야 하고, 맨 위 페이지도 https여야 합니다. 아니면 위 "허용한 사이트"에서 설명한 대로 확인을 받습니다.
  • 코드 전체가 들어가지 않는 짧은 칸: 대신 코드를 복사합니다.

1.0.1 1.0.1부터 코드 칸이라는 단서가 없는 전화번호 칸은 고르지 않습니다.

넣기에 실패하면

  1. 코드 칸을 한 번 누른 뒤 다시 시도하세요.
  2. "금고가 잠겼습니다. 잠금을 해제한 뒤 다시 눌러 주세요."가 나오면 Popout의 잠금을 해제하세요.
  3. "이 사이트에 입력할 권한이 없습니다…"가 나오면 사이트 접근을 허용하거나, 그 사이트에서 툴바의 Popout을 열어 다시 누르세요.
  4. "대상 탭이나 페이지가 바뀌었습니다. 넣을 사이트에서 다시 눌러 주세요."가 나오면 그 페이지에서 처음부터 다시 하세요.
  5. 코드가 거부되면 기기의 날짜와 시간을 확인하세요. 문제 해결을 보세요.

평가 남기기 쓰는 브라우저의 스토어에 남긴 짧은 평가가 다른 사람이 Popout을 찾는 데 도움이 됩니다.
