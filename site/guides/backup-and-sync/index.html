Backup, export, and sync

Make encrypted backups, export to other apps, restore from snapshots or the trash, and sync between devices.

Make an encrypted backup

A backup file is your safety net. Removing the extension also removes its accounts and snapshots, so save a backup file somewhere safe before you remove or reinstall it.

  1. Open the manage screen (the "Settings" button in the popup) and choose "Backup". In the toolbar popup, "Export" opens a small window for the next steps.
  2. Under "Export", leave "Format" on "Encrypted backup (recommended)".
  3. Type a "Backup password (8+ characters)" and repeat it in "Repeat the password". If it is too short you see "The password must be at least 8 characters."; if the two differ you see "The passwords do not match."
  4. If you use a password lock, type your current password in the "Enter your current password again." field.
  5. Select "Create backup".
  6. Popout reads the new file back and shows a check such as "11 of 11 included in the backup". If accounts are missing it says "Missing accounts: …. This file cannot restore all accounts."
  7. Select "Download". The file is named popout-authenticator- plus the date, with .json at the end.

The backup password is separate from your lock password. The file opens with the backup password alone, and Popout cannot reset it. Store the password apart from the file.

The file holds your active accounts with their groups, notes, important marks, site addresses, and HOTP counters. Accounts in the trash are left out. If your administrator blocked exporting, you see "Your administrator has blocked exporting."

Compare the formats

"Format" offers six choices. The first one is the encrypted choice; the rest are not encrypted.

FormatWhat you getWho can read itLeft out
"Encrypted backup (recommended)"A .json file, encrypted with your backup passwordPopout Authenticator, with the passwordTrash
"Unencrypted backup (JSON)"A .json file with readable secret keysPopout AuthenticatorTrash
"otpauth link text"A .txt file, one otpauth:// link per lineApps that import otpauth:// linksSteam and Battle.net accounts
"CXF"A .json file in the FIDO Credential Exchange FormatApps that import CXFEverything except time-based (TOTP) accounts
"QR per account"One QR code on screen for each accountApps that scan standard authenticator QR codesSteam and Battle.net accounts
"Google batch QR"QR codes in the format of Google Authenticator's export, several accounts per codeApps that read Google Authenticator export codesSteam and Battle.net, and accounts that do not use 6 or 8 digits and a 30-second period

Accounts that a format cannot hold are listed under "These accounts cannot be exported in the selected format."

Every format except the encrypted backup contains your secret keys in a form anyone can read. For these, Popout shows "Secret keys are saved without encryption. Keep the file somewhere others cannot access." and you tick "I understand the risk" before "Create backup" is enabled. Delete the files and close the QR codes when you are done.

The backup reminder

When you have at least three accounts, the popup can show a strip: "Back up your accounts." with "Back up" and "Later".

  • It appears if you never made a backup. After that, it appears again only when your last backup is older than 30 days and your accounts have changed since.
  • "Back up" opens the "Backup" screen. "Later" hides the strip for 7 days.
  • A backup counts when you select "Download" and the check finds every account the chosen format can hold. In version 1.0.0 this can hide the reminder even when the format skipped some accounts, so use "Encrypted backup (recommended)" to include all of them. QR codes do not count.

1.0.1 From version 1.0.1, an export that skips some accounts no longer hides the reminder.

Restore from a backup file

  1. Select + → "Add account" → the "Backup file" tab → "Choose a backup file."
  2. Pick your Popout backup. For an encrypted one, Popout says "This backup is encrypted. Enter its password." Type it in "Backup password" and select "OK". A wrong one gives "The password is incorrect."
  3. A result message shows how many accounts were added and how many were skipped as duplicates. Accounts you already have are never overwritten.

The same tab reads the otpauth text and CXF files that Popout exports. For files from other apps, see Moving from Authy Desktop and other apps.

1.0.1 From version 1.0.1, the file picker also offers .2fas files, and CXF imports list the entries they could not read.

Check a backup without changing anything

In "Backup", select "Open backup comparison", then "Choose backup file". Enter the "Backup password" if asked and select "Compare". Popout lists each account as "Match", "Missing from backup", "Authentication details differ", or "Review needed", and shows accounts that are "Only in backup". Your accounts do not change. It compares the details in the file and does not guarantee that a website sign-in works.

Export to other apps

  1. In "Backup" → "Export", pick one of "otpauth link text", "CXF", "QR per account", or "Google batch QR" in "Format".
  2. Tick "I understand the risk" and enter your current password if asked.
  3. Select "Create backup". Files get a "Download" button.
  4. For QR formats, scan the code from the other app. Use "Previous" and "Next" to step through the codes (for example "Code 1 of 2"), then "Close".

Check the other app's import options first. If it cannot read the format you chose, try another row of the table above.

Recovery snapshots

Popout saves the previous version of your account list as a snapshot each time the list changes. It keeps the latest 30 snapshots plus the newest one for each of the last 30 days. Snapshots live in the extension, not in a file, so they are gone if you remove it.

  1. Open "Backup" and find "Restore from a snapshot". Each row shows a time and a count, such as "… · 5 accounts". A "locked" mark means it was saved with a lock; if your current vault key cannot open it, Popout asks for that snapshot's password. If there are none, you see "No snapshots".
  2. Choose "Add missing accounts only" to bring back accounts that are not in your list now.
  3. Or choose "Restore entire list". Popout warns that your current list is replaced and saved as a new snapshot. Select "Restore" to continue.
  4. If the snapshot used another password, enter "the password used to save this snapshot" and select "OK".
  5. You see "Restored N accounts." when it is done.

1.0.1 From version 1.0.1, turning on the password lock also re-encrypts older snapshots, so none of them keeps readable secret keys.

Raw copy

"Save raw copy" saves a copy of the stored vault and settings. "Import from a raw copy" adds its accounts back and asks for "the password of this copy" if needed. If Popout cannot read your vault ("Could not read the vault. Do not reset or remove the extension."), save a raw copy first and check the recovery options on that screen.

1.0.1 From version 1.0.1, importing a raw copy also works when the current vault is damaged.

Trash

Deleting an account asks "Move this account to trash? It will be permanently deleted after 30 days." and offers "Move to trash".

  1. Open the manage screen and choose "Trash". Each row shows the days left, such as "30 days left".
  2. Select "Restore" to bring the account back.
  3. Select "Delete permanently" and confirm to remove one account for good. "Empty trash" removes all of them. Both say "This cannot be undone."

1.0.1 From version 1.0.1, restoring from the trash no longer creates a duplicate account.

Account history

History turns one account back to an earlier state without touching the others. It uses the snapshots above, so it reaches back only as far as they do.

  1. Save any edits first. Unsaved input is not part of the history.
  2. Open the account for editing and select "Account history".
  3. Choose "Review changes" on a saved version. "Load earlier versions" shows older ones.
  4. Select "Restore this version". Only the listed fields change. Other accounts and the list order stay as they are.

"Restoring an old key does not change the key registered with the website." For HOTP accounts, the key, type, and counter stay unchanged "to prevent code reuse".

Sync between devices

Sync uses your browser's own sync service. It is offered on Chrome, Edge, and Firefox. On Safari, the Settings screen says "This browser does not support syncing between devices. Use a backup file to move your accounts to another device." Popout has no server of its own.

Turn it on

  1. Set a password lock first. See Lock and protect your accounts. Sync is on by default but only runs once a lock exists. Without one, the status reads "Set up a lock to sync your accounts with encryption."
  2. Open the manage screen → "Settings" → "Sync" and check "Sync with devices signed in to the same browser account".
  3. Sign in to the same browser account on your other device and set up Popout there. If it says "Accounts were synced from another device. Merge them using the vault password set on that device.", follow that message.
  4. Select "Sync now" to sync at once. The status changes to "Synced."

Each account (secret key, service, name, notes, group, site addresses) is encrypted with your vault key before upload. Deleting an account is passed on to your other devices. Your settings, field buttons, and site usage history are not synced.

"Allow syncing without a lock" sends secret keys without encryption. "Without a vault lock, secret keys are sent to other devices on the same browser account without encryption." Set a lock instead.

Firefox

Firefox asks for permission to send data through Firefox Sync. Until you allow it, the status says "Firefox needs your permission to send encrypted accounts through Firefox Sync." Select "Allow".

1.0.1 From version 1.0.1, if no lock is set the message reads "Firefox needs your permission to send accounts through Firefox Sync. Turn on a lock to send them encrypted."

HOTP counters

A HOTP account has a counter that goes up each time you use a code. Backups and sync carry the counter, so a restored or synced account continues from where it was saved. If two devices disagree, a code could be used twice.

1.0.1 From version 1.0.1, a HOTP counter never goes backwards during sync. Accounts removed by "Restore entire list" also stay removed.

Turn off or delete sync data

  • To stop syncing, clear "Sync with devices signed in to the same browser account". The status says "Sync is off."
  • To remove the shared copy, tick the box that says "Delete the sync data shared with other devices. Accounts saved on each device stay unchanged.", then select "Delete sync data". You see "Sync data deleted."

1.0.1 From version 1.0.1, "Delete sync data" also turns sync off on this device, so the data is not uploaded again.

Other messages you may see: "Not enough sync space.", "Locked, so it could not sync. Unlock first.", and "Checking data from another device. Try again shortly."
