Share a code with a link

Send a link that shows an account's codes for a limited time, with an optional password. The link never contains the secret.

What a share link is

A share link lets another person see the sign-in codes of one account for a limited time. For example, you can let a teammate sign in to a shared "Acme Mail" account once, without sending them the secret key.

The link does not contain the secret key. Instead, Popout calculates the codes for the time you choose, such as the next hour, and puts only those codes into the link. The codes are scrambled (encrypted) inside the link. Without a password, the key for that scrambling is stored in the link itself, so anyone who has the link can open it. With a password, the key comes from the password, and the other person must type it.

The link opens a plain web page, elitekid.github.io/popout-authenticator/share/. The part of the address after # holds the data. Popout itself has no server that stores your links.

The codes in a link are real codes. Anyone who can open the link can use them during the sharing time. Share only with people you trust.

Create a link

  1. Open Popout and find the account.
  2. Open the account's "⋯" menu (right-clicking the account opens the same menu).
  3. Choose "Share codes". If you use a vault password, Popout first says "Enter your password once more." Type it and select "OK".
  4. Check the options below, then select "Create link".

Only accounts of the time-based (TOTP) type can be shared. HOTP, Steam and Battle.net accounts have no "Share codes" item. The item is also missing while codes are hidden. If a link cannot be made, you see "This account cannot be shared."

The options

OptionWhat it does
Name shown above the codeThe name the other person sees. It starts as the service and account name, for example "Acme Mail alex@example.com". You can change it. Names are cut at 64 bytes.
Valid for"5 min", "15 min", "30 min" or "1 hour". The default is "1 hour".
Password (optional)Locks the link with a password. Without it, anyone with the link can view the codes.

Pick the shortest time that works for you. When the time is over, the link has no codes left.

If you set a password, send it by a different route than the link, for example by phone while the link goes by chat. Popout reminds you with "Send the password separately." Popout clears the password field once the link is made.

Copy the link or show the QR code

After you select "Create link", Popout shows:

  • A QR code, when the link is short enough to draw one. The other person can scan it with a phone.
  • The link itself, and a "Copy link" button. After copying, the button reads "Link copied".
  • "Codes are available until" and the end time.

Select "Done" to close the window. Popout does not keep a list of the links you made. If you lose a link, create a new one.

What the other person sees

They do not need Popout. Opening the link shows a page with:

  1. The name you set, above the current code.
  2. The code, split in two halves. They select the code to copy it ("Select the code to copy it.").
  3. "Time left" until the next code, and "Valid until" with the end time.

If you set a password, the page first says "Enter the password to open this link." They type it and select "Open". A wrong password shows "Incorrect password." The page uses Korean for browsers set to Korean, and English otherwise.

Other messages: "This share link has expired." after the end time, "Not available yet." if their device clock is behind, "Unable to open this share link." for a damaged or cut-off link, and "No share link found." when the address has no data.

Limits you should know

  • You cannot cancel a link. The codes are already inside it, and there is no server where you could switch it off. It stops only when the time ends. Choose a short time, because Popout cannot end it sooner.
  • The link can be copied and forwarded. A password limits this, but a person who knows the password can pass it on too.
  • The link is not tied to one device or person. Several people can open it during the time.
  • After the end time the page shows no more codes. The link and the encrypted data still exist wherever it was sent, so delete the messages that contain it.
  • The codes follow device clocks. If the clock of your device or theirs is far off, codes can seem wrong.
  • The page is loaded from the web. The codes are read on their device from the data in the link.

Related features
