Moving from the original Authenticator extension

The original "Authenticator" extension's latest GitHub release is v8.0.2 (2024-09-15) — see its releases (checked 2026-10-15). Popout Authenticator reads its backups directly, and it builds on the original extension's MIT-licensed code.

Get Popout Authenticator

Steps

  1. In the original extension, go to Settings → Backup and choose "Download Backup File" or "Download Password-Protected Backup". (Menu names are from its v8.0.2 source; other versions may differ.)

    • "Download Backup File" is a plain backup. It saves authenticator.txt, or authenticator.json if you have Steam or Battle.net accounts.
    • "Download Password-Protected Backup" saves an encrypted authenticator.json. The button appears after you set a password in Settings → Security.
  2. Install Popout Authenticator with the buttons above.
  3. In Popout, select + → "Add account" → "Backup file" tab → "Choose a backup file." From the toolbar popup, a small window opens for choosing the file.
  4. If the backup is encrypted, Popout asks: "This backup is encrypted. Enter its password." Type the password you set in the original extension in "Backup password" and select "OK". If the password is wrong, you see "The password is incorrect."
  5. A result message shows how many accounts were added. Accounts that already exist (same type and same secret) are skipped. Existing accounts are never overwritten.

  6. Afterwards:

    • Compare a code in both extensions before you remove anything.
    • Delete the downloaded backup file if it was plain. It contains your secret keys.
    • Consider setting a password in Popout.

Encrypted backups made by much older versions of the original extension may not open. If that happens, download a plain backup instead.
