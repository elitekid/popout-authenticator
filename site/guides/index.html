Guides

Step-by-step guides for each feature. They describe version 1.0.0, the version in the stores now; changes coming in 1.0.1 are marked.

Using Popout

  • Get started: install and add your first accountInstall Popout Authenticator and add accounts from a QR code, a link, or by typing the secret.
  • Popup, separate window, and side panelOpen your codes in the toolbar popup, a separate window, or the side panel, and keep a long list tidy with search, groups, and pins.
  • Fill codes into sign-in pagesFill a code with one click, the right-click menu, a keyboard shortcut, or a button next to the code field, on the sites you allow.
  • Lock and protect your accountsSet a password lock, keep the recovery code, unlock with a passkey, choose auto-lock, and hide codes while sharing your screen.
  • Backup, export, and syncMake encrypted backups, export to other apps, restore from snapshots or the trash, and sync between devices.
  • Share a code with a linkSend a link that shows an account's codes for a limited time, with an optional password. The link never contains the secret.
  • Need to share a 2FA code? Temporary links and their limits for small teamsChoose between personal access, a shared vault, and a temporary code link, and learn what the link cannot do.
  • TroubleshootingWhat to do when codes are rejected, filling does not work, the vault will not unlock, or an import fails.
