Moving from Authy Desktop and other apps

Pick your app below. For the original Authenticator extension, see its own guide.

Get Popout Authenticator

Authy

Twilio ended Authy Desktop (Windows, macOS, Linux) on 2024-03-19 — Twilio's end-of-life guide (checked 2026-10-15). Authy does not offer exporting tokens — Export or Import Tokens in the Authy app (checked 2026-10-15).

So you set each account up again:

  1. For each service, sign in and open its two-factor settings.
  2. Set up the authenticator app again. The service shows a new QR code.
  3. Add the new QR code in Popout: + → "Find QR on screen", or + → "Add account" → "QR code" tab.
  4. Keep Authy until every account works in Popout.

If you already have a JSON list of otpauth:// links from an earlier export, Popout can read it via "Backup file".

Google Authenticator

  1. On the phone, open the app's Menu → Transfer codes → Export codes (English app labels; see Google's instructions, checked 2026-10-15).
  2. Unlock, select the accounts, and choose Next. The app shows one or more QR codes.
  3. In Popout, select + → "Read QR with camera", or + → "Add account" → "QR code" → "Choose QR code images" (you can choose several images at once).
  4. If there are several QR codes, scan each one.

These QR codes contain your secret keys. Don't share them, and delete any screenshots or photos afterwards.

Other apps

Use an unencrypted export unless the table says otherwise. For encrypted Aegis, 2FAS, and Bitwarden files, Popout tells you to export an unencrypted file from that app instead (for example, "Export an unencrypted file from the Aegis app and use that.").

Import into Popout

  1. In Popout, select + → "Add account" → "Backup file" tab → "Choose a backup file." From the toolbar popup, a small window opens for choosing the file.
  2. For an encrypted backup from 2FA Authenticator, Popout asks: "This backup is encrypted. Enter its password." Type it in "Backup password" and select "OK". If the password is wrong, you see "The password is incorrect."
  3. A result message shows how many accounts were added. Accounts that already exist (same type and same secret) are skipped. Existing accounts are never overwritten.

If the file is not recognized, Popout shows "Unknown format".

Afterwards

  • Compare a code in both apps before you remove anything.
  • Delete unencrypted export files. They contain your secret keys.
