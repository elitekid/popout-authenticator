Site match check: fill only on the address you set

Popout compares the page you are on with the site addresses you saved for an account. It helps keep a code from going automatically to a similar-looking address.

  5. Secure pages only

What is compared

Each account can have "Site addresses", for example example.com. When you fill a code, Popout compares the address of the page that holds the code field with the addresses saved for that account. It compares against the addresses you set, so the result does not depend on how a page looks or what it is called.

To add an address, open the account's "⋯" menu → "Edit" and type it under "Site addresses (separate with commas or new lines)". See Fill codes into sign-in pages for the ways to fill.

What counts as a match

The page counts as a match only when its host is the same as a saved address, or is a subdomain of it.

Saved addressPage hostMatch
example.comexample.comYes
example.comlogin.example.comYes, a subdomain
login.example.comexample.comNo
example.comexample.com.other.testNo

Popout does not group addresses by their base domain. Some domains, such as github.io, give every subdomain to a different owner, so a shared base domain says nothing about who runs the page.

The sites you turned on for the "Fill code" button beside the code field also count as saved sites for that account.

The check uses the page that actually holds the code field, not only the tab's address. A frame on the page is checked by its own address.

When the site does not match

If the page is not a saved site of the account, Popout does not fill. It asks in the popup first, showing the host it found and "Check the address before filling." You choose:

  • "Remember and fill": saves the host as a site address of this account, then fills. Later fills there match.
  • "Fill once": fills now and saves nothing. It never auto-submits, even if auto-submit is on.
  • "Cancel": fills nothing.

Check the address in the browser's address bar before you choose.

Which account is picked for you

The shortcut, the right-click menu item, and the highlighted account in the popup pick an account for you. They pick only an account whose saved site matches the page. They do not use a similar name or how often you used an account.

The suggestion list in the popup may also show accounts with a similar name. Those are candidates you can see and choose yourself. Filling one of them on a site that is not saved for it brings up the question above.

Secure pages only

  • Popout fills only on https pages. The local test addresses localhost and 127.0.0.1 are also allowed over http.
  • It checks both the address of the top page and the address of the document being filled. A frame from another site is not filled just because the top page is trusted.
  • Frames such as about:blank are refused.

A habit to avoid

If you press "Remember and fill" out of habit, the check protects you less: a similar-looking address becomes a saved site. Press it only when the address in the address bar is the one you mean.
