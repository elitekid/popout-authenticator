# 스토어 등록정보 — 한국어

## 이름 (manifest appName, 1.0.1)
팝업 인증 도구 — 2단계 인증 OTP 코드

## 요약 (manifest appDesc, 132자 이내)
오픈소스 2단계 인증(OTP) 도구. 일회용 코드를 팝업·창·사이드 패널로 보고, 비밀번호로 잠글 수 있습니다. 다른 인증 앱 백업도 가져옵니다.

## 상세 설명
(평문으로 붙여 넣는다: ** 표시는 뺀다. 다른 제품 이름은 크롬 스팸 FAQ대로 5개까지.)

Popout Authenticator(팝업 인증 도구)는 2단계 인증(2FA) 일회용 코드를 브라우저에서 바로 보여 줍니다. 툴바 팝업, 분리 창, 사이드 패널 중 편한 곳에서 볼 수 있습니다. 표준 TOTP·HOTP 코드를 만들고, 오픈소스(MIT)이며, 계정 수 제한이 없고, 가입이나 서버가 필요 없습니다.

**다른 인증 앱에서 옮기기**
- 인증 도구(Authenticator, authenticator.cc) 확장의 백업 파일을 가져옵니다. 비밀번호를 건 백업도 됩니다.
- Google Authenticator™ 내보내기 QR 코드와 호환됩니다.
- 다른 인증 앱의 평문 백업과 표준 자격 증명 교환(CXF) 파일을 가져옵니다. 지원하는 앱: https://elitekid.github.io/popout-authenticator/ko/guides/from-authy-and-other-apps/
- 일부 앱의 암호화 백업은 열 수 없습니다. 그런 경우 그 앱에서 평문 백업으로 내보낸 뒤 가져와 주세요.

**필요한 곳에서 바로 열기**
- 툴바 팝업, 분리 창, 사이드 패널(파이어폭스는 사이드바)에서 열 수 있습니다.
- 검색, 그룹, 고정, 좁은 보기로 계정이 많아도 깔끔하게 정리됩니다.
- 지금 보고 있는 사이트의 계정을 먼저 알려 주고, 클릭·오른쪽 클릭·단축키로 코드를 넣습니다.
- 고른 사이트에서는 코드 입력 칸 옆에 넣기 단추를 띄울 수 있습니다.

**편한 방법으로 계정 추가**
- 지금 탭, 카메라, 이미지, 클립보드에서 QR 코드를 읽습니다.
- otpauth:// 링크를 붙여 넣거나 비밀키를 직접 입력할 수 있습니다.
- TOTP·HOTP는 SHA-1·SHA-256·SHA-512와 6~10자리를 지원하고, Steam(5문자)과 Battle.net(8자리) 코드도 지원합니다.

**안전한 보관**
- 계정은 기기 안에 AES-256-GCM으로 암호화한 금고에 보관합니다. 비밀번호를 정해야 금고 키가 보호됩니다. 비밀번호가 없으면 키가 데이터와 함께 기기에 저장됩니다.
- 비밀번호(Argon2id), 복구 코드, 패스키 잠금 해제(파이어폭스 제외)로 잠글 수 있고, 자동 잠금 시점을 고를 수 있습니다.
- 코드를 쓰기 전에 기기 인증을 요구하거나(파이어폭스 제외), 직접 정한 단축키로 코드를 가릴 수 있습니다.
- 통계·광고·개발자 서버가 없습니다. 소스 코드는 공개되어 있습니다.

**잃어버리지 않게**
- 암호화 백업, otpauth 텍스트·CXF·QR 코드로 내보내기를 지원합니다.
- 브라우저 자체 동기화로 내 기기끼리 동기화합니다(크롬·엣지·파이어폭스). 비밀번호 잠금을 켜면 암호화해서 보냅니다.
- 복구 스냅샷, 30일 휴지통, 계정 변경 기록을 제공합니다.
- 컴퓨터 시계가 틀려 코드가 맞지 않을 때 시계 확인으로 알려 줍니다.

**비밀키 대신 코드만 공유**
- 앞으로 5~60분 동안의 코드만 보여 주는 링크를 보낼 수 있고, 비밀번호도 걸 수 있습니다. 링크에는 비밀키가 담기지 않습니다.

**알아 둘 점**
- 개발자가 운영하는 클라우드 백업은 없습니다. 백업은 직접 보관하는 파일이고, 동기화는 브라우저 자체 동기화를 씁니다.
- 패스키 잠금 해제와 기기 인증은 파이어폭스에서 쓸 수 없습니다. 사파리판은 macOS 전용입니다.

20개 언어를 지원합니다. 조직용 관리 정책을 지원합니다.

Popout Authenticator는 개인 개발자가 만듭니다. 인증 도구(Authenticator, authenticator.cc) 확장의 MIT 라이선스 코드와 번역을 바탕으로 했으며, 그 개발자들과는 관계가 없습니다.

Google Authenticator는 Google LLC의 상표입니다.
