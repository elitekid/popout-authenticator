# ストア掲載情報 — 日本語

## 名前 (manifest appName, 1.0.1)
Popout Authenticator — 二段階認証コード

## 概要 (manifest appDesc, 132文字以内)
オープンソースの 2FA 認証アプリ。ワンタイムコードをポップアップ・別ウィンドウ・サイドパネルで表示し、パスワードでロックできます。他のアプリのバックアップも読み込めます。

## 説明
(プレーンテキストで貼り付ける。** は外す。他社製品名はクロームのスパム FAQ に従い 5 つまで。)

Popout Authenticator は、二段階認証(2FA)のワンタイムコードをブラウザですぐに表示します。ツールバーのポップアップ、別ウィンドウ、サイドパネルのうち使いやすい場所で開けます。標準の TOTP・HOTP コードを生成し、オープンソース(MIT)で、アカウント数の制限はなく、登録やサーバーは不要です。

**他の認証アプリからの移行**
- Authenticator 拡張機能(authenticator.cc)のバックアップファイルを読み込めます。パスワード付きのバックアップにも対応します。
- Google Authenticator™ のエクスポート QR コードに対応しています。
- 他の認証アプリの平文バックアップと、標準の認証情報交換(CXF)ファイルを読み込めます。対応アプリ(英語): https://elitekid.github.io/popout-authenticator/guides/from-authy-and-other-apps/
- 一部のアプリの暗号化バックアップは開けません。その場合は、先にそのアプリで平文のバックアップをエクスポートしてください。

**必要な場所で開く**
- ツールバーのポップアップ、別ウィンドウ、サイドパネル(Firefox ではサイドバー)で開けます。
- 項目を絞った検索や複数語での検索、名前順の並べ替え、グループ、ピン留め、アイコン、コンパクト表示で、アカウントが多くても整理できます。
- 開いているサイトのアカウントを先に示し、クリック・右クリック・キーボードショートカットでコードを入力します。
- グローバルショートカットで、重要マークを付けた最初の 3 つのアカウントのコードをコピーできます。ブラウザが背面にあっても使えます(Chrome・Edge・Whale)。
- 選んだサイトでは、コード入力欄の横に入力ボタンを表示できます。
- 複数のアカウントを選んでまとめてゴミ箱へ移したり、グループ名の変更や解除を一度にしたり、アカウント名をコピーしたりできます。

**アカウントの追加方法**
- 今のタブ、ほかのアプリのウィンドウ、カメラ、画像、クリップボードから QR コードを読み取ります。
- otpauth:// リンクを貼り付けるか、シークレットキーを手入力できます。
- TOTP・HOTP は SHA-1・SHA-256・SHA-512 と 6〜10 桁に対応し、Steam(5 文字)と Battle.net(8 桁)のコードにも対応します。

**安全な保管**
- アカウントは端末内の、AES-256-GCM で暗号化された保管庫に保存されます。保管庫の鍵を守るにはパスワードを設定してください。パスワードがないと、鍵はデータと一緒に端末に保存されます。
- パスワード(Argon2id)、復旧コード、パスキーによるロック解除(Firefox を除く)でロックでき、自動ロックのタイミングを選べます。
- コードを使う前に端末の認証を求めたり(Firefox を除く)、自分で決めたショートカットでコードを隠したりできます。
- コピーしたコードを 30 秒・1 分・2 分・5 分後にクリップボードから消せます(Safari を除く)。
- 分析・広告・開発者のサーバーはありません。ソースコードは公開されています。

**アクセスを失わないために**
- 暗号化バックアップと、otpauth テキスト・CXF・QR コードへのエクスポート。
- ブラウザ自体の同期を使った端末間の同期(Chrome・Edge・Firefox)。パスワードロックをオンにすると暗号化して送ります。
- 復元スナップショット、30 日間のゴミ箱、アカウントの変更履歴。
- パソコンの時刻のずれでコードが合わないときは、時計の確認で知らせます。

**シークレットではなくコードだけを共有**
- 今後 5〜60 分間のコードだけを表示するリンクを送れます。パスワードも設定できます。リンクにシークレットは含まれません。

**知っておいてほしいこと**
- 開発者が運営するクラウドバックアップはありません。バックアップは自分で保管するファイルで、同期はブラウザ自体の同期を使います。
- パスキーによるロック解除と端末の認証は Firefox では使えません。Safari 版は macOS のみです。
